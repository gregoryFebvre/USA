# Démarchage de dons

Application web statique (GitHub Pages) + API Google Apps Script + Google Sheet comme seule source de données. Sans base de données, sans serveur, sans coût.

- `frontend/` : site (HTML/CSS/JS sans build)
- `api/Code.gs` : API Apps Script à coller dans la Sheet
- `docs/DEPLOIEMENT.md` : mise en service pas à pas

Modifier les données : directement dans la Sheet (onglet `Démarchage`, ID et dates automatiques) ou via le site avec un code éditeur.
